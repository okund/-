微信开发者工具浏览，

需要IntelliJ IDEA启动环境，编写MsSQL数据库，已有数据库查询脚本

需在application.yml文件配置数据库连接，以及百度智能云AI人脸识别模型配置


课程考勤模块：开发了“上课打卡”功能，前端获取当前时间戳与地理位置，后端校验课程时间段与地点匹配度后，写入 MySQL 数据库生成考勤记录。
实习考勤模块：针对校外实习场景，设计了独立的实习打卡逻辑，支持长周期、多地点的打卡记录存储与查询。


AI 人脸识别集成
对接百度智能云人脸识别接口，设计了“拍照-上传-比对”的完整交互流程。
将采集的人脸特征值与数据库中的用户信息进行实时比对，有效防止代打卡作弊行为，提升了考勤数据的真实性。

数据展示: 在首页通过API请求获取个人考勤数据，并渲染出“查寝打卡”、“上课打卡”、“实习打卡”的累计次数及连续打卡天数等信息。

其他业务模块开发
请假申请: 开发线上请假流程，学生可填写请假理由、时间并提交申请，等待后台审核。
消息通知: 实现了公告列表的展示，用于向所有用户推送系统通知或重要消息。


项目亮点
防作弊机制:
设计并实现了“GPS定位 + 人脸识别”的双重验证打卡机制，确保考勤数据的真实性和可靠性。
用户体验优化:
在用户未连接到后端服务时，前端会进行提示如“未连接到后端服务器”，而非直接崩溃，提升了应用的健壮性和用户体验。
状态管理:
利用小程序的生命周期函数和本地缓存优化了用户状态如连续打卡天数的展示，减少了不必要的网络请求
数据可视化与交互
首页通过聚合查询 SQL 语句，实时统计并展示用户的“连续打卡天数”、“缺勤次数”等关键指标，为用户提供直观的考勤概览
