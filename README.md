微信开发者工具浏览，

需要IntelliJ IDEA启动环境，编写MsSQL数据库，已有数据库查询脚本

需在application.yml文件配置数据库连接，以及百度智能云AI人脸识别模型配置


核心考勤打卡功能
查寝打卡模块: 调用 wx.getLocation 获取用户地理位置，结合后端地理围栏逻辑，实现指定范围内的定位打卡；同时集成人脸识别验证功能，通过调用相机接口并上传图像，完成活体身份核验，有效防止代签。
上课打卡模块: 实现了基于“限时定位”和“动态码”（如定时刷新的二维码）的双重验证打卡模式，确保学生在正确的时间和地点完成签到。
接入百度智能云AI人脸识别大模型，识别准确率高达98%

数据展示: 在首页通过API请求获取个人考勤数据，并渲染出“查寝打卡”、“上课打卡”、“实习打卡”的累计次数及连续打卡天数等信息。

其他业务模块开发
请假申请: 开发线上请假流程，学生可填写请假理由、时间并提交申请，等待后台审核。
消息通知: 实现了公告列表的展示，用于向所有用户推送系统通知或重要消息。


项目亮点
防作弊机制:
设计并实现了“GPS定位 + 人脸识别”的双重验证打卡机制，确保考勤数据的真实性和可靠性。
用户体验优化:
在用户未连接到后端服务时，前端会进行友好提示（如“未连接到后端服务器”），而非直接崩溃，提升了应用的健壮性和用户体验。
状态管理:
利用小程序的生命周期函数和本地缓存 (wx.getStorageSync) 优化了用户状态（如连续打卡天数）的展示，减少了不必要的网络请求
